What you're looking at. Per-pixel TTP regression on the locked MAD k=1.5 ABCD ntcRaw preprocessing. Training set = the 5 dose-response chips (1e5–1e9), wells 0–3 only, every pixel inheriting its chip's qLAMP mean TTP. Test set = the SD multiplex chip's 5 dilution wells.
  • 5 distinct training labels, so the constant-mean baseline MAE is the bar to beat (≈3.84 min — printed below per cell).
  • Per-pixel predictions and the well-mean of those predictions are both shown. Per-well MAE is usually better than per-pixel MAE because intra-well noise averages out.
  • Curves are downsampled by 4× for transport (every 4th sample of the 450-step trace). Time axis in minutes.
Three R²-style numbers — read carefully.
  • pixel R² = standard R² (1 − SS_res/SS_tot) computed across all ~5000 test pixels with their per-pixel labels (5 distinct values, repeated per well). Strict accuracy metric.
  • well R² = standard R² across the 5 SD-test well-means (predicted vs ground truth). Strict accuracy metric, n=5.
  • well Pearson² = squared Pearson correlation across the 5 SD-test well-means. Measures trend rather than magnitude. This is the metric the rule-based methods report: TTP (deployed baseline) = 0.976, SDM v2 = 0.988, Cy0 v2 = 0.762, all computed the same way on n=5 chip-means. The regression's well Pearson² is comparable to those numbers; well R² is the stricter cousin (it penalises predictions that track the trend but compress the range).
