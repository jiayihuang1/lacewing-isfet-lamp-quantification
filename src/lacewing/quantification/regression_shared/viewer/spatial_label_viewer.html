What you're looking at. For each (chip, well), K-means clusters the surviving active pixels into K=8 groups using normalised trace shape as the feature (smoothed trace, per-pixel zero-mean unit-std).
  • Left: spatial map of the well's active pixels coloured by cluster id. Pixels with the same colour share the same shape cluster — they may or may not be spatially contiguous.
  • Right: cluster-mean smoothed signal, one trace per cluster, colour-matched to the spatial map. The red dashed vertical line is the well's qLAMP-derived ground-truth TTP for reference.
  • Singleton clusters (size 1) are outlier pixels — k-means isolates them. Trivial to handle in the labelling step.
This page is read-only; labelling will be added once the clustering looks reasonable.
