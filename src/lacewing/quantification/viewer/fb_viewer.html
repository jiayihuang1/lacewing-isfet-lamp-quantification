F-B methodology + extraction-rule viewer loading …

What this shows. Every F-B (sliding-window classifier) checkpoint is trained on windowed slices of the ISFET trace and outputs a per-window post-amp probability curve. This viewer shows, for a chosen window configuration + well:
  • Part A — Methodology. How the raw ISFET trace maps to the per-window probability curve. Grey lines = every test pixel in the well; bold red = well-mean.
  • Part B — Extraction-rule comparison. Same well, but pick any of the 16 TTP-extraction rules and see where each rule would place TTP. Rug plot below shows per-pixel TTP predictions from the selected rule.
Seed 0 across all four F-B window configurations (W ∈ {30, 60, 90, 120} samples).
